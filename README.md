# Odoo x NMIT Bangalore Hackathon 2026

## Structure

- `frontend/`: React 19 + Vite + Tailwind CSS v4 setup.
- `backend/`: Node.js Express + Sequelize ORM + MySQL setup.


### Backend Setup
```bash
cd backend
npm install
# Set up database credentials in .env
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
